- 변수(variable): 데이터를 담는 상자
- 대입 연산자(=): 오른쪽에 있는 값을 왼쪽에 넣음
- 상수(constant): 고정된 값 (변경 불가능)

- 변수를 쓰는 이유: 값의 수정이 쉬워짐 (변수만 바꾸면 되므로)

**✅ 예시: 변수를 쓰지 않는 경우**
```javascript
alert("apple banana apple banana apple");
```
위 문자열 속 apple을 모두 orange로 바꾸고 싶을 때, 변수를 쓰지 않으면 일일히 수정해줘야 하는 번거로움이 있음

**✅ 변수를 쓰는 경우**
```javascript
var name = "orange";
alert(name + "banana" + name + "banana" + name);
```
- 그러나 위처럼 name 변수를 선언해주면, 변수 하나로 모든 내용을 한 번에 수정할 수 있음
- 문자열이 길어질수록 변수를 사용하는 방법이 더 효율적임

**🔍 추가 검색: 변수의 종류**

- var : 중복 선언 가능, 함수 레벨 스코프(전역 변수)
- let : 중복 선언 불가능, 블록 레벨 스코프(지역 변수)
- const : 상수
- 일반적으로는 var보다 let을 많이 씀

## 비동기 콜백이란?

콜백 함수는 다른 함수에 인자로 전달되어 호출되는 함수입니다.
이러한 콜백을 비동기 작업의 결과를 처리하는 데 사용할 수 있습니다.

예시를 보면 다음과 같습니다.

```js
function getData(callback) {
  setTimeout(() => {
    console.log("서버에서 데이터 가져옴");
    callback({ name: "은관" }); //서버에서 가져온 데이터
  }, 2000);
}

getData((data) => {
  console.log(data.name);
});
```

위 코드는 실제 서버에 요청하는 대신, setTimeout()으로 데이터를 가져오는 상황을 흉내 낸 예시입니다.

getData() 함수는 callback이라는 매개변수로 함수를 받습니다.

2초 뒤에 예약된 함수가 실행되면 callback()을 호출하고, { name: "동혁" }이라는 데이터를 전달합니다.

전달된 데이터는 콜백 함수에서 data라는 매개변수로 받아 사용할 수 있습니다.

즉, 비동기 작업이 끝난 뒤 실행할 함수를 미리 전달하고, 작업이 완료되면 해당 함수를 실행하는 방식입니다.

하지만 이런 비동기 콜백이 계속 중첩되면 문제가 생기는데요. 이를 콜백 지옥이라고 합니다.

### 콜백 지옥

```js
login("은관", (username) => {
  console.log(`${username}님 로그인 완료`);
  getUserInfo(username, (user) => {
    console.log(`${user.name}님의 정보를 불러왔습니다.`);
    getPosts(user.id, (posts) => {
      console.log(`${posts.length}개의 게시글을 불러왔습니다.`);
      getComments(posts[0].id, (comments) => {
        console.log(`${comments.length}개의 댓글을 불러왔습니다.`);
      });
    });
  });
});
```

이렇게 비동기 콜백이 계속 중첩되면 코드는 점점 오른쪽으로 들어가고, 구조가 복잡해져 코드를 이해하기 어려워집니다.

이런 중첩을 줄이기 위해 사용하는 것이 바로 **Promise**입니다.

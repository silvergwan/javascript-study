## 비동기 작업?

비동기 프로그래밍을 설명하기 전에 먼저 동기 프로그래밍부터 알아보겠습니다.
동기 프로그래밍은 작업을 한 번에 하나씩, 순서대로 실행하는 방식입니다.

예를 들어 다음과 같은 코드가 있다고 해보겠습니다.

```javascript
console.log("1번 작업");
console.log("2번 작업");
console.log("3번 작업");
```

이 코드는

- 1번 작업
- 2번 작업
- 3번 작업
  이렇게 작성한 순서대로 실행됩니다.

자바스크립트 코드는 기본적으로 이러한 동기적인 방식으로 실행됩니다.

동기 방식은 실행 순서를 따라가기 때문에 코드의 흐름을 이해하기 쉽다는 장점이 있습니다.
하지만 시간이 오래 걸리는 작업이 있다면 문제가 생길 수 있습니다.

앞의 작업이 끝날 때까지 뒤의 작업들이 모두 기다려야 하기 때문에, 전체 프로그램이 멈춘 것처럼 보일 수도 있습니다.
이러한 문제를 해결하는 데 사용하는 방식이 비동기 프로그래밍입니다.

비동기 프로그래밍은 작업이 완료되기를 기다리는 동안 다른 작업을 먼저 실행할 수 있도록 하는 방식입니다.

예를 들어 다음과 같은 코드가 있습니다.

```javascript
console.log("1번 작업");

setTimeout(() => {
  console.log("2번 작업");
}, 1000);

console.log("3번 작업");
```

이 코드를 실행하면 결과가 이렇게 됩니다.

- 1번 작업
- 3번 작업
- 2번 작업

setTimeout()에 들어 있는 2번 작업은 1초가 지난 뒤 실행되도록 예약되기 때문에, 기다리지 않고 다음 코드인 3번 작업을 먼저 실행하게 됩니다.

이처럼 비동기 방식을 사용하면 작업이 완료되기를 기다리는 동안 다른 작업을 실행할 수 있습니다.

하지만 비동기 작업이 완료된 후에 실행해야 하는 작업도 있을 수 있습니다.
이런 작업을 처리하는 방법 중 하나가 비동기 콜백입니다.

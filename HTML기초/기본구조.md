## 기본 구조
```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>제목</title>
</head>
<body>
  <h1>어쩌고</h1>
  <p>저쩌고</p>
</body>
</html>
```
- < !DOCTYPE html > : HTML5 문서 선언
- < HTML > : 문서 전체를 감싸는 태그
- < head > : 제목, CSS 파일 연결
- < body > : 실제 화면에 보이는 내용

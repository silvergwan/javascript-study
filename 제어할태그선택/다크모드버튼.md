- 버튼을 눌렀을 때 다크 모드가 되게 만드려면
    - body 태그에 바로 style 속성을 적는 방법으로는 사용자와 상호작용이 불가능함
    - 따라서 자바스크립트 문법으로 CSS 요소를 넣어야 함
**✅ 예시: 다크 모드 버튼 생성**
```html
<body>
  // 다크 모드 버튼
  <input type="button" value="night" onclick="
    document.querySelector('body').style.backgroundColor = 'black';
    document.querySelector('body').style.color = 'white';
  ">
  
  // 되돌리기 버튼
  <input type="button" value="day" onclick="
    document.querySelector('body').style.backgroundColor = 'white';
    document.querySelector('body').style.color = 'black';
  ">
  
  text
</body>
```
- onlcick : 클릭했을 때 상호작용할 내용
- document.querySelector('body') : body 태그를 선택
- .style.backgroundColor = 'black'; : 배경색을 black으로 변경
- .style.color = 'white'; : 글꼴색을 white로 변경

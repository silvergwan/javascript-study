**✅ 예시: 선택자의 우선순위**
```css
<style>
  .js		// '.'은 클래스를 가리킴
  {
    font-weight:bold;
    color:red;
  }
  #first	// '#'은 id를 가리킴
  {
    color:green;
  }
  span		// 모든 span 태그를 가리킴
  {
    color:blue;
  }
</style>
    
...
    
<span id="first" class="js">text</span>
```
- class(.) : 그룹화할 때 사용 (광범위하게 처리)
- id(#) : 한가지 대상만 식별 (하나만 예외처리)
- 위 코드의 결과는 text가 **초록색**으로 나옴
    - id > class > tag(span 등) 순으로 우선순위가 높음

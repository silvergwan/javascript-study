Flexbox는 요소들을 쉽게 정렬할 수 있도록 도와주는 레이아웃 시스템
브라우저의 크기가 바뀌어도 배치가 그대로 유지된다는 장점이 있음
✅ 예시

```css
// CSS 파일
.container
{
  display: flex;
  justify-content: center;  // 가로 정렬: 가운데로
  align-items: center;  // 세로 정렬: 가운데로
}

.item
{
  background-color: skyblue;
  padding: 20px;
  margin: 10px;
}
```
### 주요 속성들
- justify-content: : 가로 기준
- flex-start : 왼쪽으로
- flex-end : 오른쪽으로
- center : 가운데로
- space-between : 요소들 사이에 동일한 간격을 둠
- space-around : 요소들 주위에 동일한 간격을 둠
- align-items: : 세로 기준
- flex-start : 꼭대기로
- flex-end : 바닥으로
- center : 가운데로
- baseline : 컨테이너의 시작 위치로
- space-around : 요소들을 컨테이너에 맞도록 늘림
- flex-direction: : 정렬 방향 지정
- row : 텍스트의 방향대로
- row-reverse : 텍스트의 반대 방향으로
- column : 위에서 아래로
- column-reverse : 아래에서 위로
- order: : 요소들끼리의 구체적인 순서 지정
```css
#pond
{
  display: flex;
}

.red
{
  order: -3;  // -3번째 위치로 이동
}
```
- align-self: : 개별 요소에 적용할 수 있는 또다른 속성
    - 지정된 align-items 값을 무시하고 해당 요소에만 적용됨
- flex-wrap: : 요소들을 한 줄 또는 여러 줄에 걸쳐 정렬
    - nowrap : 요소들을 한 줄에 정렬
    - wrap : 요소들을 여러 줄에 걸쳐 정렬
    - wrap-reverse : 요소들을 여러 줄에 걸쳐 반대로 정렬
-flex-flow: : flex-direction + flex-wrap
    - flex-direction과 flex-wrap의 속성 두 개를 인자로 가짐
- align-content: : 세로 기준 (여러 줄)
    - flex-start : (여러 줄을) 꼭대기로
    - flex-end : (여러 줄을) 바닥으로
    - center : (여러 줄을) 가운데로
    - space-between : 여러 줄들 사이에 동일한 간격을 둠
    - space-around : 여러 줄들 주위에 동일한 간격을 둠
    - stretch : 여러 줄들을 컨테이너에 맞도록 늘림

< div > : 기능 없이 CSS나 자바스크립트 문법만 넣을 때 사용하는 태그 (줄바꿈 O)

< span > : < div >와 같음 (줄바꿈 X)
**✅ 예시: 비효율적인 방법**
```html
<span style="font-weight:bold;">text</span>
```
- font-weight:bold; : 해당 텍스트를 굵게 표시

- 위 방법은 적용하고 싶은 텍스트가 많아질수록 일일히 수정해야 하기 때문에 비효율적임
    - 따라서 < style > 태그를 선언해주는 방법을 사용해야 함

**✅ 효율적인 방법**
```html
<style>		// 스타일 태그 선언
  .js		// '.'은 클래스를 가리킴
  {
    // 원하는 내용 설정
    font-weight:bold;
    color:red;
  }
</style>
    
...
    
<span class="js">text</span>
```
- class="js" : 클래스를 js로 지정해주면 스타일 태그의 .js 부분이 해당 텍스트에 모두 적용됨

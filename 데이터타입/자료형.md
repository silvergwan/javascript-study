### 자바스크립트에는 총 6개의 자료형이 있음 (Boolean, Null, Undefined, Number, String, Symbol)

- Number(숫자) : 산술 연산자(+, -, \*, /)와 같이 쓰임
- String(문자열) : 작은따옴표(')나 큰따옴표(") 모두 사용 가능
  - .length : 문자열의 길이를 세줌
  - .toUpperCase() : 문자열을 대문자로 변환
  - .indexOf() : 원하는 문자(열)의 인덱스를 찾아줌
  - .trim() : 앞뒤 공백을 없애줌
- 숫자와 문자열 계산에 주의 (1+1 != "1"+"1")

### 🔍 추가 검색: 자료형의 종류

- Bigint : Number형보다 큰 수를 저장할 때 씀
- Boolean : true와 false 두 가지 값만 갖는 자료형
- Null : 존재하지 않는(비어있는) 값
- Undefined : 변수는 선언했지만 값을 할당하지 않은 상태
- Symbol : 유일하고 변경 불가능한 기본값 (객체끼리 충돌 방지를 위해 사용)
